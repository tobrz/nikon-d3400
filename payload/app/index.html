Walk me through a shot

This runs on the Pi. A tiny local model rephrases the plan when one is installed. The steps themselves are written for the D3400.

Live view

Live view works only with the mode dial on P, A, S, or M. Press Stop if the message under the picture is an error. The page stops asking after an error, so it does not keep releasing the shutter. Focus steps need the lens on M. Autofocus needs it on A.

Every menu item the body offers

Choices, on/off switches, number ranges, and text are all writable when the camera says they are. Read-only rows are shown and left alone. This list is the menu, read over USB, not a fixed catalog.


  


  

    
Everything the camera reports

    
This is the raw report from the body. Lens identity is included as the camera sends it: Lens ID, Lens Type, and the focal-length range. Those are numbers, plus millimeters, not the name printed on the lens.

Lightning

    
Sprays the shutter, then copies the new frames off the card. A digital light sensor can be added later on GPIO 17. USB is slower than the bolt, so leave the camera in manual focus and manual exposure first.

    
    
    
    
    

      
      
    

    

  


  

    
Night test frame

    
Applies ISO 800, f/3.5, and a long shutter if the body allows those names, then takes one frame.

    
    

  


  

    
Time and place

    
The D3400 has no GPS of its own. SnapBridge is what puts the phone's location in the file. Leave this off when SnapBridge is not connected. The Pi then sets the camera clock from its own clock, and writes the location below into pictures after they are copied here.

    
    
    
    
    
    
    
    

      
      
      
      
    

    

  

  

    
Pictures

    
Copy a frame off the D3400, then download it onto this phone or laptop. The zip is everything already stored on the Pi.

    
On a Mac, connect to smb://nikon-d3400.local/shots as user camera. Drag the files straight into Photos. The share is read-only.

    
Offload copies every picture onto the Pi, then deletes only the copies that arrived. Anything that fails stays on the camera. The Pi copies are on the shots share for Photos.

Wi-Fi

    
On a new Pi the page is up before the camera tools are installed. Join a network that has internet here. Setup then downloads those tools. Saving a network from the Nikon-D3400 access point makes the Pi leave it, so join that same network on this phone and open http://nikon-d3400.local.

    
    
    
    
    

    

    
    
    

    
Update

    
Downloads the camera console from the public git repo and restarts this page. Pictures, saved Wi-Fi networks, and this password stay on the Pi. Raspberry Pi OS stays as it was imaged.

    
The Pi needs ethernet, or a Wi-Fi network it has joined that can reach the internet. While it is only the Nikon-D3400 access point, this button cannot download anything.
